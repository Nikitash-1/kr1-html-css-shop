# SemenA.ru — Учебный интернет-магазин семян

## Текущий статус

Проект успешно переименован в **SemenA.ru** и адаптирован под тематику магазина семян. 
Реализован вывод 6 популярных товаров с изображениями, настроена цветовая палитра (зеленые оттенки). 
Исправлена и доработана логика JavaScript: при нажатии на кнопку «Заказать» открывается модальное окно, 
а выбранный товар автоматически подставляется в скрытое поле формы. Базовые страницы приведены к единому стилю.

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина семян.

## Структура проекта

- `index.html` — главная страница (Hero-блок, преимущества, популярные товары);
- `catalog.html` — каталог товаров (фильтры, сетка товаров с кнопками заказа);
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений (включает `seed1.jpg` — `seed6.jpg` и превью);
- `js/main.js` — скрипты (логика модального окна и валидация формы);
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта;
- `sitemap.xml` — простая карта сайта.

## Используемые технологии

- HTML5 (семантическая разметка, `dialog`, `pattern`);
- CSS3 (Flexbox, CSS Grid, CSS-переменные);
- JavaScript (ES6+, работа с DOM, `dialog.showModal()`);
- Git и GitHub;
- GitHub Pages.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- изображения для каждого товара (`product-card__image`);
- модальное окно с формой заявки;
- скрытое поле (`<input type="hidden">`) для автоматического подхвата названия товара при заказе;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- JS-обработка формы (проверка `checkValidity`, сброс формы, закрытие окна);
- сообщение об успешной отправке.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root` (включая адаптированную зеленую палитру);
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css` с логическим разделением на блоки.

## Дополнительные элементы

- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню (`site-nav__list`);
- Flexbox для внутренней структуры карточек товаров (для прижатия кнопки к низу карточки);
- CSS Grid для сетки карточек (`products-grid`);
- CSS Grid для страницы каталога с фильтрами и списком товаров (`catalog-layout`).

# SemenA.ru — Учебный интернет-магазин семян

## Текущий статус

Проект полностью подготовлен к сдаче Контрольной работы №1. 
Структура расширена до 5 обязательных страниц (добавлены `product.html` и `order.html`). 
В проект внедрена семантическая таблица характеристик, реализованы все виды позиционирования 
(`relative`, `absolute`, `fixed`, `z-index`). Абсолютно все значения в CSS перенесены в переменные `:root`. 
Логика работы модального окна и валидации формы полностью отлажена.

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

- `js/main.js` — скрипты (логика модального окна и валидация формы);

## CSS-архитектура и позиционирование

В проекте используются:

- **CSS-переменные в `:root`**: вынесены все значения (цвета, шрифты, отступы, размеры, скругления, тени, `z-index`, прозрачность).
- **Семантические состояния**: `:hover`, `:focus-visible`, `:disabled`.
- **Подсветка ошибок**: через `aria-invalid`.
- **Flexbox**: для навигации и выравнивания элементов внутри карточек.
- **CSS Grid**: для сетки товаров и макета каталога.
- **Позиционирование (КР №1)**:
  - `position: relative` — на карточках товаров;
  - `position: absolute` — для бейджей («Хит», «Новинка»);
  - `position: fixed` — для кнопки «Наверх»;
  - `z-index` — для наложения бейджа на картинку и фиксации кнопки поверх контента.
